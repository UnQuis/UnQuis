## Проекты

### ⭐ [Fading Revelations: Remake](https://github.com/UnQuis/Fading-Revelations-Remake)
Мод для Mindustry — продолжение заброшенного *Fading Revelations*.
Переписан под современные версии: сюжетная кампания, мегаструктуры, свои юниты.
Полностью на Java, ~современный API движка.

### [Absolute Divinity](https://github.com/UnQuis/Absolute-Divinity)
Контентный мод для Mindustry: 60+ турелей, 6 фракций, кастомные юниты и боссы,
своя генерация планет и погода.

### [Singularity Launcher](https://github.com/UnQuis/SingularityLauncher)
Лаунчер версий Mindustry на [Arc](https://github.com/Anuken/Arc).
Сканирует папку, находит `.jar`-ники, запускает нужный.

### [ServerRack](https://github.com/UnQuis/ServerRack)
Серверная часть для кампаний Mindustry — чтобы можно было играть не в одиночку.
